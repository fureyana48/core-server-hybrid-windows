# Changelog

## [1.0.0] - 2026-08-17

Initial portfolio release.

### Added

- Core project scope and principles
- Three-device inventory structure
- Independent Win10/Win11 baseline model
- Backup destination separation
- Backup/recovery documentation
- Configuration script placeholders
- Pending-work tracking

### Known limitations

- Configuration text captures from the physical machines are not automatically copied into the repository.
- Full system-image backups are intentionally outside the repository.
- W530 backup destination details still need to be transcribed.
- Some recovery procedures remain pending verification on physical hardware.
